# Φράση — греческий для вашей жизни

Персональное Android-приложение для Захара: 157 греческих фраз, 38 вопросов экзаменатора и подготовка к ελληνομάθεια A2 Κέντρο Ελληνικής Γλώσσας.

[Скачать APK 0.4.0 для Android](https://github.com/zakgovin/GreekPhraseApp/raw/refs/tags/v0.4.0/downloads/frasi-0.4.0-android.apk)

При переходе с 0.3.1 нужна переустановка: прежний ключ подписи потерян при восстановлении облачной среды. По согласованию с Захаром 0.4.0 подписана новым ключом. Если хотите сохранить прогресс, сначала экспортируйте JSON в настройках старого приложения, затем удалите его, установите 0.4.0 и импортируйте JSON. Новый ключ закреплён проверкой сертификата и имеет зашифрованную резервную копию; [восстановление подписи](docs/SIGNING.md).

Android 8.0+, WebView 94+. Это тестовая сборка с отладочной подписью. [Установка и сборка](docs/ANDROID.md) · [Проверки и ограничения](docs/VALIDATION.md).

## Вопросы экзаменатора

В «Разговор» → «Вопросы экзаменатора» собраны все 38 вопросов из списка Захара с греческими ответами по его личным сведениям. Можно открыть отдельный ответ или пройти блок из трёх вопросов. Поиск, фильтр по теме, озвучка и сохранение незаконченного блока доступны сразу.

Подходящие карточки используются повторно; добавлено 35 полных фраз. Новые фразы также входят в обычные адаптивные занятия. Исходные 122 карточки, их ID и формат прежнего прогресса сохранены. [Все вопросы и ответы для просмотра](docs/EXAM-QUESTIONS.md).

## Как заниматься

Нажмите «Начать занятие». Сначала приложение познакомит с фразами, затем предложит собрать фразу из слов. Нажмите «Проверить», посмотрите результат и продолжайте. В собранном ответе можно удержать слово и перетащить его в другое место; отдельный крестик убирает слово. Новый порядок сохраняется. Слова для сборки показываются без конечной точки и заглавной буквы начала предложения; имена и названия сохраняют своё написание. После проверки видна фраза с правильным регистром и пунктуацией. Если не помните, кнопка «Не помню» покажет образец и вернёт фразу на повторение.

По мере успешных повторов задания меняются: собрать фразу → выбрать пропущенное слово → ответить без слов-подсказок. Четырёх оценок памяти нет: результат определяет приложение. На экране проверяется изученная формулировка; свободный ответ на экзамене может звучать иначе.

Первый блок содержит около пяти новых фраз. Следующие блоки учитывают ответы, помощь, активное время и очередь повторов. При трудностях нового меньше, при уверенных ответах — больше. Дневного лимита и настройки количества нет. Каждый блок имеет фиксированный конец: счётчик «Шаг X из Y» включает знакомство и практику. Ошибки влияют на следующие повторы, но не добавляют шаги в текущий блок. После завершения основное действие — отдохнуть; «Ещё немного» запускает короткий дополнительный блок максимум из шести шагов.

Голосовой ответ появляется только при доступном локальном распознавании греческого на Android 13+. Приложение получает распознанные слова, даёт их исправить и проверяет ответ. Это проверка слов, а не фонетики или акцента. Ошибка распознавания не считается ошибкой ученика. Пассивного диктофона больше нет; все задания доступны через слова на экране или текст.

## Возможности

- Автоматические занятия, расписание FSRS-6, пауза и продолжение с сохранённого шага.
- 14 бесед и ролей с проверкой подготовленных коротких ответов.
- 8 письменных тем с черновиками и критериями, 8 вырезанных фотографий с упражнениями, 2 аудиодиалога с ключами (1:27 и 1:44).
- Каталог 157 карточек, поиск без греческих ударений, фильтры и краткая атрибуция.
- История проверенных ответов; прежние самооценки помечены отдельно и сохранены.
- Настройка скорости озвучки, экспорт/восстановление JSON, подтверждаемый сброс.

Содержание письма проверяется по самостоятельному чек-листу. Приложение не выставляет официальный экзаменационный балл и не оценивает произвольную греческую речь.

## Данные и материалы

В APK только подготовленные фразы и тексты, восемь вырезанных изображений и два разрешённых аудиофрагмента. **Оригинальные PDF и полные MP3 не входят в приложение.** Сервер и API-ключи не нужны. Для озвучки нужен установленный локальный греческий голос Android; его установка и установка данных распознавания могут требовать интернет.

Прогресс, черновики и настройки сохраняются в SharedPreferences Android; в браузерном режиме — в LocalStorage. Голосовой ответ не создаёт пользовательских аудиофайлов. Прежние приватные записи не удаляются при обновлении и не включаются в JSON. Приложение не отправляет учебные данные на сервер. Перед удалением приложения или переносом на другой телефон экспортируйте прогресс.

Сохранены согласованные ID, 45 исходных личных карточек и 43 ссылки на задания 2015–2018 годов. Новый список имеет отдельный источник без выдуманного года или ссылки на официальный PDF; вместе с 35 новыми фразами личных карточек стало 80. Не добавляйте неизвестные биографические сведения: учебные роли не становятся фактами профиля.

## Разработка

Node.js 24+, npm; для APK также JDK 21 и Android SDK 36.

```bash
npm ci
npm run dev -- --port 5173
npm test
npm run test:e2e
npm run android:build
```

APK и отчёты о составе и подписи появляются в `artifacts/`. До сборки проверяется закреплённый сертификат. Отсутствующий или другой ключ останавливает работу, автоматическая замена запрещена. Затем проверяются ресурсы, TypeScript, production-интерфейс, Capacitor sync, Gradle assembleDebug/lintDebug, подпись и содержимое APK. Для новой среды сначала восстановите ключ по [SIGNING.md](docs/SIGNING.md).

Браузер используется для разработки и автоматических проверок. Playwright запускается последовательно в Chromium при 1440×1000 и 390×844. В cloud-среде выбирается `/usr/bin/chromium`; другой путь задаётся через `CHROMIUM_PATH`. Отчёты и снимки — в `playwright-report/` и `test-results/`, вне Git. Браузерный макет Android bridge проверяет контракт голосового ответа, а не физический микрофон.

Работайте в существующем checkout: cloud-задача уже изолирована, отдельный worktree не нужен.

## Защита исходных материалов

Присланные PDF и полные MP3 используются только для анализа. Храните их вне checkout, не копируйте в `public/`, `dist/` и Android assets. В текущей среде: `/workspace/greek-a2-study/original-exams/`.

`npm run media:check` отклоняет PDF и неописанное аудио; разрешённые клипы проверяются по SHA-256. Проверка обязательна перед каждой сборкой. Android-сборка отдельно проверяет фактический архив APK на исходники, старые ресурсы и точные контрольные суммы клипов. Для обычной сборки оригиналы и модель распознавания не нужны. Воспроизведение нарезки с FFmpeg описано в [AUDIO.md](docs/AUDIO.md).
