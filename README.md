# Φράση — греческий для вашей жизни

Персональное Android-приложение для Захара: 122 греческие фразы, интервальное повторение и подготовка к ελληνομάθεια A2 Κέντρο Ελληνικής Γλώσσας.

## Android

[Скачать готовый APK 0.2.1 для Android — 9,3 МБ](https://github.com/zakgovin/GreekPhraseApp/raw/refs/tags/v0.2.1/downloads/frasi-0.2.1-android.apk)

Основная версия — устанавливаемый APK для Android 8.0+. В приложение включены карточки, подготовленные тексты, восемь вырезанных изображений и два коротких аудиофрагмента упражнений. Оригинальные PDF и полные MP3 в приложение не входят; сервер не нужен. После подготовки JDK 21 и Android SDK 36 выполните `npm run android:build`. Файл: `artifacts/frasi-0.2.1-android.apk`. Подробности и настройка греческого голоса: [ANDROID.md](docs/ANDROID.md).

## Браузерный запуск для разработки

Нужны Node.js 24+ и npm. В предоставленной среде используется Node.js 24.19.0.

```bash
cd /workspace/GreekPhraseApp
npm ci
npm run dev -- --port 5173
```

Production-сборка и локальный просмотр:

```bash
npm run build
npm run preview -- --port 4173
```

Работайте в существующем checkout: cloud-задача уже изолирована, отдельный Git worktree не нужен.

## Что работает

- **Сегодня:** приоритет назначенных повторов, 3 новые фразы и ориентир 15 минут по умолчанию; пауза и продолжение после перезагрузки.
- **Память:** настоящий FSRS-6 через ts-fsrs; отдельные состояния понимания, речи и письма; подсказки учитываются как неуспешное самостоятельное припоминание.
- **Разговор:** 14 подготовленных бесед и ролей, вопросы на греческом, скрытые образцы, текстовый ответ или локальная запись голоса.
- **Экзамен:** 8 письменных тем с черновиками и счётчиком слов; 8 исходных фотографий; 2 вырезанных диалога (1:27 и 1:44) и задания с ключами; переход к ролевым играм.
- **Каталог:** все 122 карточки, поиск без греческих ударений, фильтры по теме, типу и году, краткое указание источников без открытия исходных PDF.
- **Прогресс:** история, отдельные навыки, отложенное припоминание после суток, реальные значения без демонстрационных результатов.
- **Настройки:** нагрузка и скорость озвучки, экспорт/восстановление JSON, подтверждаемый сброс данных.

## Данные и ограничения

Источники — присланные пользователем PDF за 2015–2018 годы и доступные MP3 за 2017–2018. Фразы автора адаптированы к личным данным; вымышленные роли и примеры помечены. Номера карточек сохранены. Само приложение и материалы не публиковались.

В Android используются локальный голос TextToSpeech, нативная запись AAC/M4A, приватное хранилище прогресса и системный выбор JSON-файлов. В браузерном режиме голос для учебных фраз предоставляется через SpeechSynthesis. Если греческий голос отсутствует, кнопка недоступна с объяснением; текст и подготовленные аудиофрагменты остаются доступны. Микрофон требует поддерживаемого браузера и безопасного контекста (HTTPS либо localhost). При отказе можно отвечать текстом.

В Android прогресс, черновики и настройки хранятся в SharedPreferences, записи — в приватных файлах приложения. В браузерном режиме используются LocalStorage и IndexedDB. Данные не отправляются на сервер. JSON-экспорт **не включает** записи голоса. Пользуйтесь экспортом перед удалением приложения, очисткой браузера или переносом на другое устройство.

Автоматически проверяются короткие ответы по аудиоключам и объём письма. Свободная речь и содержание письма оцениваются пользователем по критериям. Это не автоматическая оценка грамматики или произношения и не официальный экзаменационный балл.

Для каждого задания включён только один соответствующий диалог: без инструкций экзаменатора, второго воспроизведения и длинных пауз. Границы, длительность и контрольные суммы сохранены в src/data/audio-clips.json. Первое и немедленное воспроизведение не выдаются за отложенное припоминание.

## Проверки

```bash
npm test
npm run build
npm run test:e2e
```

Браузерные тесты используют Playwright и Chromium. В cloud-среде автоматически выбирается /usr/bin/chromium. Для другого пути установите CHROMIUM_PATH; если системного Chromium нет, заранее установите браузер Playwright (`npx playwright install chromium`).

В тестах записи применяется синтетический микрофон Chromium. Это проверка локального сохранения и воспроизведения, а не оценка реального произношения.

Браузерные сценарии запускаются на production-сборке в двух размерах: 1440×1000 и 390×844. Отчёт: playwright-report/index.html; скриншоты и трассировки: test-results/. Эти выходные файлы не включаются в Git.

## Устройство проекта

- src/data/phrases.json — исходные 122 карточки и 43 ссылки на задания.
- src/data/curriculum.ts — законченные беседы, роли, темы письма, вопросы и аудиоключи.
- src/lib/progress.ts — расписание, очередь, история, валидация и резервные копии.
- src/lib/media.ts — локальное хранение записей.
- src/pages/ — экраны и учебные сценарии.
- src/data/audio-clips.json — точные границы и контрольные суммы разрешённых аудиофрагментов.
- public/audio/ — только два вырезанных диалога.
- public/images/ — фотографии, извлечённые из присланных экзаменационных страниц.

Не добавляйте неизвестные биографические сведения вместо уточнения у пользователя. Учебные роли не должны автоматически становиться фактами его профиля.

## Правило исходных материалов

Присланные PDF и полные MP3 используются только для анализа и подготовки учебного содержания. Хранить их вне checkout приложения, не копировать в public/, dist/ или Android assets. В текущей среде исходники сохранены в /workspace/greek-a2-study/original-exams/.

`npm run media:check` проверяет разрешённые аудиофрагменты по SHA-256 и отклоняет PDF и посторонние аудиофайлы. Проверка запускается перед каждой сборкой. Android-сборка дополнительно проверяет содержимое самого APK: отсутствие PDF, точный список двух аудиофрагментов, их контрольные суммы и отсутствие старых web-ресурсов.

Подготовленные MP3 входят в репозиторий. Для воспроизведения нарезки при установленном FFmpeg: `python3 scripts/prepare-audio.py /workspace/greek-a2-study/original-exams/audio`. Модель распознавания и оригинальные записи для обычной сборки не нужны.
