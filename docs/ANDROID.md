# Android-приложение Φράση

Версия 0.2.1, Android 8.0+ (API 26), Android System WebView 94+. Идентификатор: `com.zakgovin.greekphraseapp`.

## Установка

Готовая сборка: [скачать APK 0.2.1 с GitHub](https://github.com/zakgovin/GreekPhraseApp/raw/refs/tags/v0.2.1/downloads/frasi-0.2.1-android.apk).

Готовый файл после сборки: `artifacts/frasi-0.2.1-android.apk`. Передайте его на телефон, откройте и разрешите установку из выбранного приложения, когда Android попросит. Запускайте Φράση через значок φ. Сервер и открытая вкладка браузера не нужны.

Это тестовая сборка с отладочной подписью, без Google Play. Сохраните используемый ключ вне Git для последующих обновлений с сохранением данных. В данной среде он находится в `/workspace/android-tools/user/debug.keystore`. Потеря ключа потребует удаления старой установки; перед этим экспортируйте прогресс.

## Возможности Android

- В APK включены 122 карточки, подготовленные тексты, восемь вырезанных изображений и два аудиофрагмента упражнений (1:27 и 1:44). Оригинальные PDF и полные MP3 хранятся отдельно и не входят в приложение.
- Прогресс, расписание FSRS, настройки, черновики и незаконченная сессия сохраняются в закрытом хранилище приложения. Записи — отдельные файлы AAC/M4A в данных приложения.
- Греческую озвучку обеспечивает установленный **локальный** голос Android. При его отсутствии доступна кнопка настроек синтеза речи; для установки голоса может понадобиться интернет. Другие упражнения доступны сразу.
- Разрешение микрофона запрашивается только при первой записи. Запись останавливается при сворачивании, уходе с задания или через 3 минуты. При отказе остаётся текстовый ответ.
- Экспорт и импорт JSON используют системный выбор файла Android. Формат совместим с веб-версией. Записи голоса в JSON не входят.
- В карточке можно посмотреть краткое указание источника: экзамен, год, задание и страницу. Оригинальные документы из приложения не открываются.
- Кнопка «Назад» закрывает диалог, возвращает предыдущий экран, а при отсутствии предыдущего экрана сворачивает приложение. Интерфейс учитывает системные панели и клавиатуру.

Данные не отправляются на сервер. Удаление приложения удаляет прогресс и записи; сделайте экспорт заранее. Облачная синхронизация и автоматический балл за свободную речь не предусмотрены.

## Сборка

Нужны Node.js 24+, JDK 21, Android SDK Platform 36, Build Tools 36.0.0 и Platform Tools. Пакеты Capacitor фиксируются в package-lock.json; Gradle Wrapper 8.14.3 проверяет SHA-256 дистрибутива.

```bash
npm ci
# В этой Linux x86_64 cloud-среде, если SDK/JDK ещё не установлены:
python3 scripts/setup-android.py
npm run android:build
```

Установщик использует `/workspace/android-tools`, проверяет опубликованные контрольные суммы JDK и Android CLI и принимает лицензии Android SDK. Для другого расположения задайте `FRASI_ANDROID_TOOLS`. Для уже установленного SDK задайте `JAVA_HOME` и `ANDROID_HOME`; Python-установщик не нужен. В managed cloud сборка использует настроенный прокси и системное хранилище доверенных сертификатов Java; TLS-проверки включены.

Команда собирает ресурсы, выполняет Capacitor sync, Gradle `assembleDebug` и `lintDebug`, проверяет подпись APK и сохраняет рядом SHA-256. Перед сборкой проверяются разрешённые ресурсы; после сборки проверяются записи внутри APK и контрольные суммы двух аудиофрагментов. Включение PDF или полных записей останавливает сборку. Кэши, локальные пути, ключи и APK не включаются в Git. В конфигурации нет внешнего `server.url`.

```bash
npm run android:sync  # обновить ресурсы Android после изменения интерфейса
npm run android:open  # открыть проект в Android Studio
adb install -r artifacts/frasi-0.2.1-android.apk
```

## Проверка на эмуляторе

Используется Android 15 / API 35 / Google APIs x86_64. Для эмулятора дополнительно установлены `emulator` и `system-images;android-35;google_apis;x86_64`. В среде нет KVM, поэтому запуск выполняется программно (`-accel off -gpu swiftshader -no-window`) и занимает больше времени. Итоги фактически выполненных проверок записываются в [VALIDATION.md](VALIDATION.md).
