# Android-приложение Φράση

Версия 0.4.1, Android 8.0+ (API 26), WebView 94+. Package ID: `com.zakgovin.greekphraseapp`, versionCode 7.

## Установка 0.4.1

[Скачать APK 0.4.1 с GitHub](https://github.com/zakgovin/GreekPhraseApp/raw/refs/tags/v0.4.1/downloads/frasi-0.4.1-android.apk).

Поверх 0.4.0 устанавливается обычным обновлением: удалять приложение и повторно импортировать JSON не нужно. Ключ, package ID и формат прогресса сохранены. Исправлены все счётчики: 157 фраз всего, 80 личных. Версия приложения видна в настройках.

При переходе с 0.3.1 требуется удалить старое приложение: прежний ключ не сохранился после пересоздания облачной среды. Захар разрешил эту разовую переустановку. Новая версия сохраняет прежнее имя и package ID, но имеет другой сертификат.

1. При необходимости сохраните прогресс: настройки старого приложения → экспорт JSON.
2. Удалите старую Φράση и установите скачанный APK 0.4.1.
3. Если экспортировали JSON, импортируйте его в настройках новой версии.

Удаление очищает приватные данные, поэтому экспорт нужен до него. Исходные ID карточек и формат JSON сохранены. Старые аудиозаписи в JSON не входят.

Откройте скачанный файл на телефоне и разрешите установку из выбранного приложения, когда Android попросит. Запускайте Φράση через значок φ. Сервер и вкладка браузера не нужны.

Это тестовая сборка без Google Play. Начиная с 0.4.0 сборка закрепляет сертификат и прекращается при отсутствии или смене ключа. Закрытый ключ хранится вне checkout, в Git есть только зашифрованная копия. [Хранение и восстановление подписи](SIGNING.md).

## Вопросы экзаменатора

Разговор → Вопросы экзаменатора. Все 38 вопросов из списка с ответами о Захаре. Можно раскрыть ответ, выбрать свой вопрос или пройти короткий блок из трёх. Добавлено 35 полных фраз в основной курс; старые карточки и формат прогресса сохранены.

## Начало работы

«Начать занятие» → познакомиться с фразами → собрать ответ → «Проверить» → «Продолжить». При затруднении нажмите «Не помню». Приложение само выбирает задания, повторы и число новых фраз по ответам. Начальный блок — около пяти фраз; продолжить можно кнопкой «Ещё немного». Счётчик учитывает знакомство и задания. Длина начатого блока не растёт после ошибок. «Ещё немного» — максимум шесть шагов. В собранной фразе можно удержать слово и перетащить его; крестик удаляет отдельно. Точки и обычные заглавные буквы начала предложения не подсказывают порядок; имена и названия сохраняют написание. Ручного дневного лимита и четырёх оценок нет.

## Озвучка и голосовой ответ

Озвучка фраз и распознавание ответа — разные возможности Android.

Для озвучки установите локальный греческий голос TextToSpeech через настройки приложения. Установка голоса может требовать интернет; после установки приложение выбирает голос, которому сеть не нужна. Без него доступны текстовые задания и включённые аудиодиалоги.

Кнопка «Ответить голосом» появляется на Android 13+ только при установленном локальном распознавании греческого. Проверяется именно поддержка on-device языка, облачный запасной маршрут не используется. При недоступности статус объяснён в настройках. Доступность зависит от версии Android и установленного движка; наличие греческой клавиатуры само по себе её не гарантирует.

При голосовом ответе Android распознаёт слова, приложение показывает текст для исправления и проверяет его после «Проверить». Оценивается изученная формулировка, не акцент или фонетика. Разрешение микрофона запрашивается при первом голосовом ответе. Отказ, таймаут или сбой распознавания не создают учебную ошибку; всегда можно ответить на экране. Уход с задания или сворачивание отменяют микрофон. Пользовательские аудиофайлы не создаются.

## Данные и ресурсы

- В APK: 157 карточек, 38 вопросов экзаменатора, подготовленные тексты, восемь вырезанных изображений и два аудиофрагмента (1:27 и 1:44). Исходные PDF и полные MP3 исключены.
- Прогресс и черновики — в приватном SharedPreferences. Старая история и прежние приватные записи не удаляются обновлением. Старые самооценки обозначены отдельно.
- Экспорт/импорт JSON использует системный выбор файла. Записи прежних версий в JSON не входят.
- Данные приложения не отправляются на сервер. Удаление приложения удаляет приватные данные; экспортируйте их заранее.
- Источники доступны как краткая библиография без открытия оригинальных документов.
- Системная кнопка «Назад» закрывает диалоги и возвращает предыдущий экран, затем сворачивает приложение.

## Сборка

Нужны Node.js 24+, JDK 21, Android SDK Platform 36, Build Tools 36.0.0 и Platform Tools. Gradle Wrapper 8.14.3 проверяет SHA-256 дистрибутива; зависимости фиксируются lockfile.

```bash
npm ci
# Только если SDK/JDK ещё не подготовлены в Linux x86_64 cloud:
python3 scripts/setup-android.py
npm run android:key:check
# При отсутствии ключа — восстановить его по SIGNING.md.
npm run android:build
adb install -r artifacts/frasi-0.4.1-android.apk
```

Инструменты по умолчанию — `/workspace/android-tools`. Другой путь: `FRASI_ANDROID_TOOLS`; готовые SDK/JDK: `JAVA_HOME` и `ANDROID_HOME`. В managed cloud используются настроенный прокси и системное доверие Java, TLS-проверки включены. При запрете локальных механизмов Gradle внутри песочницы нужен обычный запуск Gradle во внешнем исполнительном окружении.

`adb install -r` подходит для обновлений с тем же сертификатом, начиная с 0.4.0. Переход с 0.3.1 описан выше; скрипты никогда не удаляют установленное приложение автоматически.

Команда сначала проверяет ключ, затем ресурсы, собирает интерфейс, выполняет Capacitor sync, `assembleDebug` и `lintDebug`, проверяет фактический архив APK и его сертификат. Выход: APK, `.sha256`, media-audit и signing-audit в `artifacts/`. Кэши, закрытые ключи и промежуточные сборки исключены из Git; готовые опубликованные APK находятся в `downloads/`.

В конфигурации нет внешнего `server.url`. Оригиналы, модель распознавания и сервер не нужны для обычной сборки. [Происхождение аудиофрагментов](AUDIO.md).

## Проверка на устройстве

Сборка и браузерные проверки не заменяют нативную проверку. В этой среде нет `/dev/kvm`; ранее программный эмулятор API 35 не завершил стабильную загрузку системных служб. Повторная попытка без изменения среды не выполнялась.

На физическом телефоне или стабильном эмуляторе остаётся проверить микрофон с установленным греческим распознаванием, отказ разрешения, отмену при сворачивании, системный JSON picker, кнопку «Назад», воспроизведение клипов и восстановление после force-stop. Фактические результаты: [VALIDATION.md](VALIDATION.md).
