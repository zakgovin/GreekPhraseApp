# Подпись Android и сохранение обновлений

Для обновления поверх установленной Φράση Android требует тот же закрытый ключ. Сохранить package ID или получить предыдущий APK недостаточно: APK содержит только открытый сертификат.

При восстановлении облачной среды был потерян ключ версий до 0.3.1. Для 0.4.0 Захар разрешил переустановку. Это разовая смена, а не разрешение менять подпись следующих выпусков.

## Ключ начиная с 0.4.0

- Package ID: `com.zakgovin.greekphraseapp`.
- SHA-256 сертификата: `5252f3b6ec448ce73afde179c6d3000973318eee5a1abfe7b7b04b6abb7c451d`.
- Закрытый ключ в подготовленной среде: `/workspace/android-tools/signing/frasi.keystore`, права `0600`.
- Другой путь можно передать через `FRASI_ANDROID_KEYSTORE`.
- Открытый отпечаток закреплён в `android/signing-certificate.json`.
- Зашифрованная резервная копия: `android/signing-key.backup.json`. Это AES-256-GCM с scrypt, случайной солью и случайным паролем из 32 байт. Копия безопасно хранится в Git; пароль и незашифрованный ключ туда не входят.

Приватный архив `frasi-signing-private-backup.zip` подготовлен отдельно от репозитория и передан ссылкой в чате. Он содержит ключ, файл восстановления и инструкцию. Сохраните его в своём защищённом хранилище. Сам рабочий каталог и ссылка на файл чата не гарантируют постоянного хранения.

Подготовленный ключ и приватный файл восстановления также могут сохраняться в снимке облачной среды. Для этого нужна публикация среды пользователем через настройки: сохранение черновика конфигурации не публикует снимок. Восстановление в совершенно новой задаче ещё не проверялось.

## Восстановление

Если ключ уже доступен:

```bash
npm run android:key:check
```

Если ключа нет, получите `recovery-passphrase.txt` из приватного архива и разместите его вне репозитория. Передайте только путь:

```bash
FRASI_SIGNING_BACKUP_PASSPHRASE_FILE=/private/path/recovery-passphrase.txt npm run android:key:restore
npm run android:key:check
npm run android:build
```

Вместо расшифровки можно восстановить сам `frasi.keystore` из приватного архива по указанному выше пути с правами `0600`. Имя ключа — `AndroidDebugKey`, пароль хранилища и ключа — стандартный `android`; секретом является сам закрытый ключ.

Неправильный пароль, повреждённая копия или другой сертификат отклоняются. Существующий файл не перезаписывается. Проверено восстановление точных байтов ключа в отдельную папку и совпадение сертификата. Повторная интеграционная проверка: `npm run android:key:test` с тем же приватным файлом восстановления; она работает во временной папке, не заменяя рабочий ключ.

## Правила следующих выпусков

`npm run android:build` проверяет ключ **до** запуска веб-сборки и Gradle. При отсутствии или смене ключа сборка прекращается. Gradle также требует существующий файл и не создаёт новый автоматически. Готовый APK повторно проверяется `apksigner`, а его сертификат сравнивается с закреплённым отпечатком. Рядом с APK создаётся `signing-audit.json`.

Не генерируйте новый ключ, не меняйте закреплённый отпечаток и не публикуйте несовместимый APK, чтобы обойти ошибку. Сначала восстановите резервную копию. Не добавляйте незашифрованный ключ, пароль или приватный архив в Git, публичный APK, логи или чат.
