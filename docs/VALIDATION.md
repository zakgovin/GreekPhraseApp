## Границы проверки

Нативный запуск на Android не подтверждён. При предыдущей попытке Android 15 / API 35 / Google APIs x86_64 в программной эмуляции без /dev/kvm не завершил стабильную загрузку: системные службы перезапускались, отсутствовали window/activity, появлялись DeadSystemException. Текущая версия проверена сборкой, Lint и анализом самого APK; повторный запуск заведомо нестабильного эмулятора не выполнялся.

**Не подтверждены на устройстве:** интерфейс, микрофон, MP3, системный JSON file picker, аппаратная кнопка «Назад» и восстановление после force-stop. Для этих проверок нужен физический телефон или стабильный эмулятор с аппаратным ускорением. Браузерные тесты не выдаются за нативные. Синтетический микрофон не проверяет качество реальной записи или произношение.

Свободная речь и письмо используют самооценку, не официальный автоматический балл. Vite рекомендует дополнительно разделить основной JS-чанк (~529 kB, ~154 kB gzip); это не ошибка сборки.

Инструкции среды обновлены: исходники предназначены только для анализа, обычная сборка использует готовые фрагменты и обязательные проверки упаковки. В черновике сохранён start_skill; это не публикация снимка и не проверка новой задачи.
