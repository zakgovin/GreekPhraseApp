# Занятие без управления методикой — версия 0.3

Основной поток: начать занятие → выполнить языковое задание → получить понятный результат → продолжить. Пользователь не выбирает оценку памяти, навык, количество новых фраз или алгоритм повторения.

## Основное занятие

- Первое знакомство: греческая фраза, перевод, доступная озвучка, одна кнопка продолжения.
- Автоматически проверяемые задания: восстановление фразы из слов, пропущенное слово, затем воспроизведение изученной формулировки без слов-подсказок.
- Ответ проверяется приложением. Сразу видны результат и образец; следующую фразу открывает одна кнопка. Четырёх оценок и диктофона нет.
- Ошибка или запрос помощи назначают более раннее повторение. Повтор внутри занятия появляется после других фраз, не сразу после просмотра образца. Число повторных попыток ограничено.
- Ответы с опорой и самостоятельное воспроизведение учитываются раздельно. Успех со словами-подсказками не выдаётся за свободную речь или готовность к экзамену.

## Нагрузка

- Фиксированного дневного лимита новых фраз нет; настройка удаляется из интерфейса.
- Начальная короткая сессия знакомит примерно с пятью новыми фразами. Объём следующих сессий зависит от последних проверенных ответов, помощи, активного времени и накопленных повторов.
- При ошибках уменьшается объём нового и повышается доля закрепления. При устойчивых ответах объём увеличивается постепенно.
- Короткое занятие можно продолжить следующим небольшим блоком; приложение не заканчивает учебный день после трёх карточек.
- Приоритет просроченных повторов сохраняется. Похожие новые карточки не используются как независимое подтверждение знания друг друга.

## Голос

Голосовой ответ — распознавание и проверка слов изученной фразы, без обещания фонетической оценки или оценки акцента. На Android используется доступное распознавание на устройстве. Микрофон не предлагается как пассивная запись: техническая ошибка распознавания не записывается как ошибка ученика. Если греческое распознавание недоступно, остаётся полноценное задание со словами или текстовым ответом.

В свободных экзаменационных заданиях сохраняется честное сравнение с примером; приложение не притворяется автоматическим экзаменатором. Необрабатываемые голосовые записи из пользовательского потока убираются.

## Совместимость и материалы

Сохраняются старые история, черновики, настройки озвучки и записи в приватном хранилище. Старые оценки остаются историческими самооценками; новые проверки помечаются по типу задания и способу ответа. Состояния памяти переносятся в общий учебный поток без удаления старых данных. Новые задания не требуют ручного выбора навыков.

Оригинальные PDF и полные MP3 остаются вне приложения. В сборке по-прежнему только 122 карточки, подготовленные тексты, восемь вырезанных изображений и два коротких аудиофрагмента. Обязательная проверка содержимого APK сохраняется.
