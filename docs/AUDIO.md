# Аудиофрагменты упражнений

Исходные записи предоставлены пользователем только для подготовки курса. Полные MP3 и оригинальные PDF не входят в приложение и находятся вне его checkout. В APK включены только два отдельных диалога, по одному проходу для каждого упражнения.

| Упражнение                             | Границы в исходной записи | Длительность файла | Файл                       |
| -------------------------------------- | ------------------------- | ------------------ | -------------------------- |
| Запись на экзамен, 2017, задание 4     | 27:03.250–28:30.650       | 1:27.432           | exam-registration-2017.mp3 |
| Заказ еды по телефону, 2018, задание 4 | 27:01.150–28:45.000       | 1:43.889           | food-order-2018.mp3        |

Границы определены по структуре записи, паузам и локальному распознаванию греческой речи. Вырезаны полные реплики от приветствия до прощания. Инструкции «Έχετε ένα λεπτό…», второй проход и длинные экзаменационные паузы исключены. Внутренние естественные паузы диалога сохранены. Проверено соответствие обоих диалогов существующим вопросам и ключам. Автоматическое распознавание использовалось для поиска и проверки границ; его черновые ошибки не переносились в учебные тексты.

MP3 перекодированы в моно 44,1 кГц / 64 кбит/с. Исходная громкость сохранена. Суммарный размер двух фрагментов — 1 531 069 байт. В [audio-clips.json](../src/data/audio-clips.json) записаны точные границы, фактическая длительность, размеры и SHA-256 исходников и фрагментов.

Для воспроизведения нарезки нужен FFmpeg и исходные MP3 в отдельной папке:

```bash
python3 scripts/prepare-audio.py /workspace/greek-a2-study/original-exams/audio
npm run media:check
```

Скрипт проверяет SHA-256 исходников и полученных фрагментов. Изменение FFmpeg или параметров кодирования может изменить байты файла; обновлять манифест следует после проверки получившегося аудио. Для обычной сборки уже подготовленные фрагменты доступны в public/audio/, исходники не нужны.
