**Устанавливайте поверх 0.4.0. Удалять приложение не нужно:** ключ, package ID и формат прогресса сохранены.

При переходе с 0.3.1 нужна согласованная разовая переустановка из-за потери прежнего ключа: сначала экспорт JSON, затем удаление, установка новой версии и импорт. Для перехода с 0.4.0 это не требуется.
