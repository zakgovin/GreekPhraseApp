Android 8.0+, WebView 94+. Откройте скачанный APK на телефоне. Устанавливайте поверх предыдущей версии: package ID, сертификат и формат прогресса сохранены. Это тестовая сборка с отладочной подписью.

Занятие теперь само проверяет ответы: фраза → короткое упражнение → результат → продолжение. Четыре оценки и пассивная запись убраны. Количество нового подбирается по ответам и повторениям; дневного лимита нет.
