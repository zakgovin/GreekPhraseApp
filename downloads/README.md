# Φράση 0.4.4 для Android

[Скачать APK](https://github.com/zakgovin/GreekPhraseApp/raw/refs/tags/v0.4.4/downloads/frasi-0.4.4-android.apk)

В версии 0.4.4 уменьшена высота карточек на главной и убраны подписи источников из упражнений. Выбранные слова исчезают из банка. Основное занятие на следующий день становится длиннее после дополнительной практики.

Версию 0.4.4 можно установить поверх 0.4.2 или 0.4.3 с сохранением прогресса. При переходе с 0.4.1 или более ранней версии сначала экспортируйте прогресс в JSON, затем удалите старое приложение, установите 0.4.4 и импортируйте JSON. Аудиозаписи в экспорт не входят.
